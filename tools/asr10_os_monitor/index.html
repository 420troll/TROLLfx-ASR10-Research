Evidence and limitations

Host GPR events are shown with their CPU writer PC and, when available, caller PC. Reversible edit windows report writes observed after a panel Up/Down action; this does not by itself establish a complete parameter curve or prove audible effect. Saved evidence contains LCD states, selected register events, and local registry status. It excludes ROM/disk bytes and arbitrary emulator output.
