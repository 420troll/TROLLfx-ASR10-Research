# Graphics pack credits

- The custom brushed panel, LCD frames, cards, state indicators, tab and Q-Link reference badges, and TROLLfx lockup are original TROLLfx graphics generated by `tools/graphics/generate_asr10_retro_graphics.py` for this repository.
- The knob, fader, toggle, push-button and segmented-button PNGs are generated from inMusic Brands' Akai Force SDK UI kit. The applicable SDK MIT notice is included as `SDK-MIT-NOTICE.txt`.
- No font files are redistributed. The artwork generator uses a system-installed DejaVu Sans font for raster previews; editable text remains SDK-native in the plugin UI.
- No Ensoniq logo, proprietary factory program data, ROM, firmware, screen capture, or paid editor artwork is included.
